# Sem Frescura English

App para aprender inglês com a **Brenda**, uma professora de IA (Claude) debochada e sem filtro — do zero (A1) até nível nativo (C2).

## Como usar
1. Abra `index.html` no navegador (Chrome recomendado, por causa do microfone).
2. Em ⚙️, cole sua chave da API da Anthropic (console.anthropic.com), escolha seu nível e a personalidade.
3. Bora:
   - **Conversa** — chat com a professora; ela corrige seu inglês. Use 🎤 para falar e toque nas frases destacadas para ouvir a pronúncia.
   - **Trilha** — 35 aulas de A1 a C2 (to be, tempos verbais, phrasal verbs, gírias, palavrões, idioms, entrevista de emprego...). Cada aula concluída dá XP.
   - **Vocabulário** — flashcards com repetição espaçada, cartas próprias e geração automática pela IA.

## Personalidades
- 🔥 **Sem filtro** — palavrão liberado (sem ofensas preconceituosas). Conteúdo adulto.
- 😏 **Debochada** — zoeira leve.
- 😇 **Educada** — sem palavrão.

A chave da API, o progresso e a conversa ficam salvos só no `localStorage` do seu navegador.
Como a chave fica no navegador, use o app só para você; para publicar para outras pessoas, coloque um backend que guarde a chave no servidor.
